# Nebula Theme

Shopify theme for **Nebula** — Galaxy Star Projectors.

## Connect to Shopify
1. Online Store → Themes → Add theme → Connect from GitHub
2. Select `abrorismurzaev2-cpu/nebula-theme` branch `main`
3. Publish the theme

## Product page
- Gallery + thumbs
- Price + compare-at
- Variant buttons
- Add to cart (AJAX)
- Description, reviews, FAQ

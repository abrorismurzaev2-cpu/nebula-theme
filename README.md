# Nebula Theme

## CRITICAL — Publish Nebula CRO
In Shopify Admin:
1. Online Store → Themes
2. Find **Nebula CRO**
3. Click **Publish**

Until you publish Nebula CRO, the live site (theme "Nebula") will NOT show price, variants, or new photos.
